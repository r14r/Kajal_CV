## What it does

Capture coursework, add notes, move tasks from “To do” to “Done”, and filter or search the list. It keeps data in SQLite.

## What to explore

- Streamlit forms, tabs and progress metrics.
- Task editing, validation and persistent storage.
- Search and status filtering.
- Storage tests using temporary databases.

## Run it

From `projects/study-planner/`, install the requirements and run `streamlit run app.py --server.address 127.0.0.1 --server.port 8502`. Open `http://127.0.0.1:8502/`. The project README includes setup and tests.
