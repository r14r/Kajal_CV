# Northstar Studio - animated site

A responsive, multi-section concept website built with semantic HTML, CSS artwork and vanilla JavaScript. The studio and case studies are fictional design demonstrations.

## Run

For the Streamlit edition, install `requirements.txt` and run `streamlit run streamlit_app.py`. On Community Cloud select `main` and `projects/animated-portfolio/streamlit_app.py` as the entry point. It has a sidebar, animated hero and project cards. The Google Fonts request is optional; system fonts provide a fallback.

The original browser edition still opens from `index.html` directly. No build step, accounts or server are required for that version.

## Explore

- Use the navigation links or scroll through Work, Process, About and Contact.
- On a narrow screen, open the accessible navigation menu.
- Use Tab and Shift+Tab to navigate by keyboard. Reduced-motion settings disable animations.
- The contact link opens a mail app addressed to a demonstration address; replace it with a real address before publishing.

## Files

- `index.html`: accessible sections and navigation.
- `styles.css`: responsive layout, visual cards, motion and reduced-motion rules.
- `script.js`: mobile menu and reveal-on-scroll behaviour.
