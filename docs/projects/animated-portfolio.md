## What it does

This fictional studio website has an animated hero, section navigation, CSS-built visual case studies, a mobile menu and scroll-triggered reveals. It is a design demonstration rather than a real commercial studio.

## What to explore

- Semantic sections, skip link and keyboard-friendly navigation.
- Responsive layouts and a mobile menu with an accessible expanded state.
- Motion that respects the visitor's reduced-motion preference.
- Visual artwork made in CSS without an image download.

## Run it

Open `projects/animated-portfolio/index.html` in a browser. The page works without a server; optional web fonts fall back to system fonts offline. The contact link uses a demonstration email address and must be changed before public use.
