## What it does

Capture coursework, add notes, move tasks from “To do” to “Done”, and filter or search the list. It runs locally and keeps its data in SQLite.

## What to explore

- A responsive form and list interface.
- A JSON API with validation and persistent storage.
- Search and status filtering in the browser.
- API tests for the main task lifecycle.

## Run it

From `projects/study-planner/`, run `python3 server.py` and open `http://127.0.0.1:8762/`. Full setup and tests are in the project README.
